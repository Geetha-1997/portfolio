01 · about

From learning the fundamentals to running production-grade pipelines.

I got into DevOps the way most engineers in this field do — by getting tired of manual, error-prone deployments and wanting a system that just works, every time. That curiosity turned into hands-on practice with the modern DevOps toolchain: containers, orchestration, infrastructure as code, and CI/CD.

I'm currently building real projects on AWS — provisioning infrastructure with Terraform and CloudFormation, containerizing applications with Docker, and automating releases with GitHub Actions and Jenkins. This portfolio itself is one of those projects: it's deployed to S3 through a CI/CD pipeline I built and version-controlled on GitHub.

I'm looking for an entry-level to junior AWS DevOps Engineer role where I can keep building on this foundation alongside an experienced team.
